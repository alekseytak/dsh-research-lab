# Исключено из анализа: сломанная песочница

Эти ячейки сняты с `BENCH_ROOT` **относительным** путём. `sandbox-exec -f <профиль>`
резолвит путь профиля относительно `cwd` дочернего процесса, поэтому профиль не находился
и **каждый `bash` падал до исполнения** (`No such file or directory`). Песочница не
включалась ни разу.

Признак: `denied = 0` во всех ячейках, тогда как дымовой тест с абсолютным путём давал
`denied = 2`.

Поэтому все ячейки здесь **недействительны** и в анализ не входят. Сохранены как след
инцидента, а не как данные. См. `code/run-bench.mjs` (фикс `resolve(ROOT)`) и раздел
отклонений в `methods.md`.
