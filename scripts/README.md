# Скрипты

Оба скрипта только читают файлы: они ничего не записывают, не обращаются к сети и не выполняют команды из содержимого.

## validate-workspace.mjs

```bash
node scripts/validate-workspace.mjs .
```

Проверяет обязательные файлы и каталоги, структуру исследований в `outputs/`, обязательные разделы Markdown, ключи `manifest.yaml`, запрещённые статусы публикации и отсутствие секретоподобных строк. Код выхода 1 при ошибках.

## ergo-score.mjs

```bash
node scripts/ergo-score.mjs library/ergo/ledger.example.jsonl
```

Считает метрики ERGO по журналу ходов: долю повторов в окне шести ходов, движение маркера мира, наличие нового факта и признак незавершённой операции. Печатает вердикт эргопризона и условия остановки. Код выхода 2 при ошибке схемы журнала. Описание метрики и скилла: `library/ergo/README.md`.
