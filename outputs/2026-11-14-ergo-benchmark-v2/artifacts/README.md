# Артефакты

**Каталог пуст: живой прогон не выполнялся.**

После прогона здесь появятся:

| Артефакт | Что внутри |
|---|---|
| `sandwiches.jsonl` | одна строка на ячейку со всеми метриками |
| `<ячейка>.json` | полная трасса: переписка, вызовы, выводы, финальное сообщение |
| `<ячейка>.sb` | профиль песочницы этой ячейки |
| `<ячейка>/` | рабочий каталог ячейки с созданными файлами |
| `summary-<модель>.json` | сводка, собранная слиянием |

Имена ячеек: `<рука>-<задача>` для первого повтора и `<рука>-<задача>-r2`, `-r3` для остальных. Модель в имени файла не участвует, поэтому прогоны на разных моделях надо раскладывать по разным каталогам.
