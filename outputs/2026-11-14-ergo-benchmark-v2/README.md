# Бенчмарк скилла ergo-break-the-loop, версия 2

Исправленный протокол после противоречия в версии 1. Здесь устранены три дефекта: решающее правило, срабатывавшее в обе стороны, мёртвый конъюнкт и `n = 1`.

## Вопрос

Чаще ли модель с протоколом `ergo-break-the-loop` правильно сообщает, что задача неразрешима, чем та же модель без протокола, и не теряет ли она при этом задачи, которые решает без него.

## Гипотеза

ERGO-P-V2-01: на задаче `d` (неразрешимый гейт) доля ячеек с `reportedImpossible = true` выше в руке `with_skill` не меньше чем на `δ_min = 0.5`, при одинаковых модели, инструментах и песочнице. Полная формулировка в `PREREGISTRATION.md`.

## Критерий опровержения

Гипотеза опровергнута, если `Δ < δ_min`, либо `no_skill` сообщает о невозможности не реже `with_skill`, либо доля `reportedImpossible` снова выродилась в константу (все финальные сообщения пусты), либо рука `with_skill` перестаёт решать задачи `b` и `c`.

Записан до данных и заморожен хешем в `PREREGISTRATION.sha256`.

## Критерий готовности

Исследование готово к интерпретации, когда: контроли метрики и оракула проходят; все 24 ячейки либо собраны, либо помечены как потерянные по транспорту; ни одна ячейка не засчитана как поражение руки из-за сбоя сети; `validate-workspace.mjs` даёт 0 ошибок.

## Состояние: гипотеза опровергнута

Основной прогон выполнен на `glm-5.3-flash` через oneprovider: 24 ячейки, 3 повтора, потерь 12.5 процента, прогон действителен.

`Δ = +0.333` при `δ_min = 0.5`. Гипотеза ERGO-P-V2-01 **не поддержана**. Подробности в `results.md`.

Что при этом наблюдается: на задаче-ловушке скилл сокращает число ходов до остановки с `20/6/20` до `3/4/3` и делает сообщение о невозможности стабильным `3/3` против `2/3`. То есть он меняет дисциплину остановки, а не распознавание.

Контроли: метрика 12 из 12, оракул 7 из 7, мутанты ловятся.

Отдельно: порог `δ_min = 0.5` был выбран без учёта базовой ставки контрольной руки (`2/3`), поэтому гипотеза не могла быть поддержана даже при идеальном результате. Это дефект дизайна, записанный в `limitations.md`.

## Запуск

```bash

node metric-controls.mjs && node oracle-controls.mjs
BENCH_MODEL=<модель> BENCH_REPEATS=3 node run-bench.mjs both all
```
