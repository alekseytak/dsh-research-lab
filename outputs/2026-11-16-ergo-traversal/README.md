# Исходная идея, попытка вторая: доля пройденных состояний

Проверяется первоначальная метрика протокола `K_erg = fraction_of_states_visited`, но с настоящим знаменателем.

## Вопрос

Различает ли доля пройденных состояний агента, который застрял, от агента, который нашёл прямой маршрут.

## Гипотеза

ERGO-P-V5-01: на задаче с большим перечислимым пространством состояний и существующим прямым маршрутом рука `with_skill` проходит меньшую долю состояний, чем `no_skill`, при равной доле решённых задач.

## Критерий опровержения

Обе руки решают задачу и проходят одинаковую долю состояний, либо обе руки проходят всю долю, либо доля не вычисляется из-за отсутствия знаменателя.

## Критерий готовности

Контроли метрики обхода проходят, обе руки получают одинаковые условия, знаменатель задан задачей, а не выведен из поведения модели.
