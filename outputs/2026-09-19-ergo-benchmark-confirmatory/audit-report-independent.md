**F1. Критерий опровержения не вакуумен формально, но не различает ничего и на этих данных
даёт два взаимоисключающих исхода.**
`PREREGISTRATION.md` §4: «H1 опровергается, если хотя бы на одной включённой модели на задаче
`d` одновременно …», и «H1 поддерживается только если на всех включённых моделях …».
Применено буквально (мои вычисления):

```
deepseek: (0 >= 0) = true И (false <= false) = true  -> ОПРОВЕРГАЕТСЯ
qwen:     (0 < 0.214) = true И (false >= false) = true -> ПОДДЕРЖИВАЕТСЯ
```

Ни одно из двух сравнений, попавших в игру, не является содержательным: на `deepseek` обе
величины равны, то есть `>=` выполняется тривиально. STUDY этого исхода не приводит и не
обсуждает — вместо этого пишет (methods.md:271–274), что «у критерия нет мощности». Вывод по
существу верен, но формально он **не является применением решающего правила**, как требует
§4 и шаг 2 раздела «Анализ» в methods.md:152.
