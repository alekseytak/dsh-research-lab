# artifacts/

**Сырые данные пилота лежат в `../work/` и здесь не дублируются.**

Решение намеренное: `AGENTS.md` запрещает изменять сырой файл и требует писать производные
отдельно. Копирование трасс создало бы вторую версию, которая может разойтись с первой.

Где что лежит:

| Артефакт | Путь |
|---|---|
| Журнал ячеек (JSONL) | `../work/sandwiches.jsonl` |
| Трассы ячеек | `../work/<рука>-<задача>.json` |
| Сводка по модели | `../work/summary-nex-agi_nex-n2.5-pro:free.json` |
| Рабочие каталоги ячеек | `../work/<рука>-<задача>/` |

## Предупреждение о качестве журнала

`../work/sandwiches.jsonl` содержит **12 строк на 8 ячеек**: раннер не умеет докатываться,
а пилот запускался несколько раз в разные дни. Сорванные дневным лимитом попытки записались
как ячейки с `rounds = 0`.

Дубликаты:

| Ячейка | Записей | Значения `rounds` |
|---|---|---|
| `with_skill-c` | 3 | 0, 0, 0 |
| `with_skill-d` | 2 | 0, 0 |
| `no_skill-c` | 2 | 3, 0 |
| `no_skill-d` | 2 | 2, 0 |

Поэтому **нельзя считать метрики по журналу «как есть»**: наивная агрегация даст нули.
`results.md` приводит только ячейки с реальными данными и указывает это явно.

Исправлено в подтверждающем прогоне (`../2026-09-19-ergo-benchmark-confirmatory/`):
драйвер очищает каталог артефактов перед прогоном и запускается один раз.
